# 策略 2：20% SCHD 原逐级版（部署包）

`config.py`、`config_v5.py`、`regime_v5.py`、`state_machine.py` 原样取自
`auto-quant/strategy2/sgs` 的 2026-10-20 G2 冻结版本，作为基础状态机保留。
用户于2026-10-21明确选择将20% SCHD原版接入 Bot。当前生效配置见
[DEPLOYED_RULES.json](DEPLOYED_RULES.json)；`FROZEN_RULES.json` 和 `FROZEN_RULES.md` 保留原GPIQ版本的历史快照，不能代表当前部署配置。

| QQQ趋势 | 当前目标规则 |
|---|---|
| 上涨／强上涨 | SCHD最低目标20%＋动态TQQQ；波动率控制按TQQQ→SPMO/QQQM等权组合→SCHD→SGOV逐级分配 |
| 中性震荡 | 100% SCHD目标 |
| 下跌／强下跌 | 通常为20% SCHD＋80% SGOV；保留原风险预算逻辑 |

信号仍跟踪QQQ，进入比率1.035、退出比率1.01，上涨确认4天、下跌确认2天。
基础波动目标15%、20日收盘价窗口、最小缩放0.3、5%调仓带与13美元预留保持原规则。
没有采用MQQQ、平级SCHD组合、8%／10%快速退出或分步买回覆盖规则。
底仓是目标下限，实际权重会随价格、费用、现金预留和调仓带变化。

`sgs.live` 接入 Alpaca 只读历史行情：复权收盘序列用于趋势/波动率，未复权上一交易日收盘用于参考碎股数量。
初次从固定起点预热；之后持久化状态并逐日回放漏掉的交易日。行情、波动率或交易日历不完整时暂停建议。
基础状态机仍用 `GPIQ` 命名内部收入角色；`sgs.live.income_sleeve` 同时将该角色的全部目标权重和
逐级风险预算的波动率输入映射到真实SCHD。GPIQ不再参与趋势、波动率计算或买入目标，未采用QQQ代理SCHD。

每天按用户实际填报的持仓与现金计算差额；单边滑点预算改为与本轮主回测一致的20bps，另估佣金。
支持碎股建议，数量向零截断至六位小数；手续费仍是估算模型，并非券商报价。
卖出建议先于买入建议，买入金额受现金及预计卖出所得约束。ETF 范围外的证券保持不变。
已有GPIQ纳入用户分配给S2的持仓市值，目标为零，只生成卖出转仓建议；不会修改用户持仓记录或假定卖出已成交。
GPIQ缺少参考报价时，仅有该旧持仓的用户暂停建议；没有GPIQ的用户不依赖其历史或报价。
这是盘前建议，不是回测成交回放：参考收盘价不等于随后开盘成交价，用户记录的现金才是可用余额，
不会推定分红已到账、推定已成交或自动创建订单。用户未更新成交记录时可再次收到未完成调整的提醒。
比例划分产生的小于一股的份额也参与调整；小于最小建议精度的尾差保留，不建议超额卖出。
源研究快照仍保留原整股回测记录，不宣称盘前建议等价于回测开盘成交。

升级时在 `BOT/` 执行 `alembic upgrade head`（新增0016报告版本字段），再启动原服务。
旧GPIQ快照自动失效并重新预热；旧版每日报告不会继续发送，会按新版本重新生成。
迁移保留持仓、现金及历史报告，不需要删除数据库。本次代码接入不自动启动Bot。

运行：安装本包后由 BOT 的 `daily_service.py` 调用。`tests/` 保留适用于部署包的原配置/状态机测试；
不包含研究 CLI、回测器或研究数据依赖。整合测试位于 BOT/tests/test_daily_strategies.py。

接入核对见[ADOPTION_CHECK.json](ADOPTION_CHECK.json)：与冻结SCHD20研究基线逐日比较
2012-04-24至2026-10-19的3,643个交易日，四种趋势标签一致，目标权重最大误差约7.4e-15。
这只验证策略目标一致，不代表Alpaca与研究行情逐笔相同，也不保证实际成交或未来收益。
如另有可信的本地研究数据，可用 `tests/verify_research_parity.py --research-root <研究目录>` 重现；
该可选工具不运行账户回测，不属于运行包依赖。
