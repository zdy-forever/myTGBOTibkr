# 策略 2：上涨SCHD15% · 震荡SCHD20% · 平衡版（部署包）

`config.py`、`config_v5.py`、`regime_v5.py`、`state_machine.py` 原样取自
`auto-quant/strategy2/sgs` 的 2026-10-20 G2 冻结版本，作为基础状态机保留。
用户于2026-10-22确认切换到上涨15% SCHD下限、震荡20% SCHD＋80% SGOV的平衡版。当前生效配置见
[DEPLOYED_RULES.json](DEPLOYED_RULES.json)；`FROZEN_RULES.json` 和 `FROZEN_RULES.md` 保留原GPIQ版本的历史快照，不能代表当前部署配置。

| QQQ趋势 | 当前目标规则 |
|---|---|
| 上涨／强上涨 | SCHD最低目标15%＋动态TQQQ；削减的TQQQ仓位直接转入SCHD，不经过SPMO/QQQM |
| 中性震荡 | 20% SCHD＋80% SGOV目标 |
| 下跌／强下跌 | 通常为20% SCHD＋80% SGOV；保留原风险预算逻辑 |

信号仍跟踪QQQ，进入比率1.035、退出比率1.01，上涨确认4天、下跌确认2天。
仅STRONG_UP进攻波动参数改为20%（TQQQ按3倍换算为60%，不是组合波动上限）。
其他趋势沿用基础波动目标15%；20日收盘价窗口、最小缩放0.3、5%调仓带与13美元预留保持原规则。
当前ALL_UP分类将确认上涨归入STRONG_UP；下跌和强下跌的原始分配逻辑不变；震荡固定为20% SCHD＋80% SGOV。
没有采用MQQQ、平级SCHD组合、8%／10%快速退出或分步买回覆盖规则。
底仓是目标下限，实际权重会随价格、费用、现金预留和调仓带变化。

`sgs.live` 接入 Alpaca 只读历史行情：复权收盘序列用于趋势/波动率，未复权上一交易日收盘用于参考建议数量。
初次从固定起点预热；之后持久化状态并逐日回放漏掉的交易日。行情、波动率或交易日历不完整时暂停建议。
基础状态机仍用 `GPIQ` 命名内部收入角色；`sgs.live.income_sleeve` 同时将该角色的全部目标权重和
其他趋势风险预算的波动率输入映射到真实SCHD；STRONG_UP直达配置只根据TQQQ波动缩放进攻。GPIQ不再参与趋势、波动率计算或买入目标，未采用QQQ代理SCHD。

每天按用户实际填报的持仓与现金计算差额；单边滑点预算改为与本轮主回测一致的20bps，另估佣金。
普通补仓和小幅调仓向下取整为整股，同时满足单笔至少80美元、预计单边手续费不超过参考成交额0.5%。
手续费预算采用IBKR Tiered首档：整股每股0.0035美元、最低0.35美元、上限成交额1%；碎股部分为成交额1%与0.01美元中的较高者；每单另留0.05美元外部费用缓冲。
混合整股与碎股退出保守地分开估算两部分佣金；这不是券商报价，缓冲不保证覆盖全部费用，实际以订单预览为准，换汇成本另计。
80美元来自0.40美元费用预算除以0.5%，是执行成本折中，尚未进行新执行规则的历史收益回测。
通常单只ETF调仓差额达到S2总资产的5%才建议交易，比较实际持仓和目标而非两次报告的权重。
目标金额以扣除13美元预留后的可投资资产计算。清仓不受5%调仓带与上述成本门槛限制；TQQQ减仓（含波动控制）以及震荡／下跌／强下跌中的非SGOV减仓豁免成本门槛，但部分卖出仍遵守原5%调仓带。
必要卖出向零截断至六位小数，保持清仓精度；卖出释放资金后的买入也须满足新的金额及费用门槛。不足门槛时现金等待，不为凑单超买或挪到其他ETF。
400美元账户原5%调仓带为20美元，普通调整还须通过80美元及费用过滤；例如TQQQ从72.9%变为75.7%，仅此差额约11美元，通常不交易。
首次升级后，目标归零的旧SPMO/QQQM会建议退出，即使金额较小。
卖出建议先于买入建议，买入金额受现金及预计卖出所得约束。ETF 范围外的证券保持不变。
已有GPIQ纳入用户分配给S2的持仓市值，目标为零，只生成卖出转仓建议；不会修改用户持仓记录或假定卖出已成交。
GPIQ缺少参考报价时，仅有该旧持仓的用户暂停建议；没有GPIQ的用户不依赖其历史或报价。
这是盘前建议，不是回测成交回放：参考收盘价不等于随后开盘成交价，用户记录的现金才是可用余额，
不会推定分红已到账、推定已成交或自动创建订单。用户未更新成交记录时可再次收到未完成调整的提醒。
比例划分产生的小于一股的份额也参与调整；小于最小建议精度的尾差保留，不建议超额卖出。
源研究快照仍保留原整股回测记录，不宣称盘前建议等价于回测开盘成交。

升级时在 `BOT/` 执行 `alembic upgrade head`（至少包含0016报告版本字段；本次不新增迁移），再启动原服务。
旧GPIQ、SCHD逐级版和20%底仓直达版快照自动失效并重新预热；旧版每日报告不会继续发送，会按新版本重新生成。
迁移保留持仓、现金及历史报告，不需要删除数据库。本次代码接入不自动启动Bot。

运行：安装本包后由 BOT 的 `daily_service.py` 调用。`tests/` 保留适用于部署包的原配置/状态机测试；
不包含研究 CLI、回测器或研究数据依赖。整合测试位于 BOT/tests/test_daily_strategies.py。

接入核对见[ADOPTION_CHECK.json](ADOPTION_CHECK.json)：与选定的平衡版名义开盘研究账户逐日比较
2012-04-24至2026-10-19的3,643个交易日，四种趋势标签一致，目标权重最大误差小于1e-10。
这只验证策略目标一致，不代表Alpaca与研究行情逐笔相同，也不保证实际成交或未来收益。
如另有可信的本地研究数据，可用 `tests/verify_research_parity.py --research-root <研究目录>` 重现；
该可选工具不运行账户回测，不属于运行包依赖。
