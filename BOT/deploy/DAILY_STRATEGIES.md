# 每日双策略部署

依次安装 BOT、BACKEND/strategy1、BACKEND/strategy2 三个包、备份已有数据库、执行 `alembic upgrade head`，再启动。
迁移 0015 新增策略现金、个人股票池、S2 状态快照及每日报告表，保留旧现金/持仓/订阅/历史。
旧现金视为公共现金（CASH 0），旧 CSV 的 current_cash 行继续兼容。

2026-10-22起，S2采用平衡版：上涨SCHD最低目标15%＋动态TQQQ（20%进攻波动参数，削减后直达SCHD），震荡目标20% SCHD＋80% SGOV，
下跌/强下跌通常20% SCHD＋80% SGOV；不加入MQQQ或快速退出覆盖规则。
必须升级到迁移0016（`alembic upgrade head`），为每日报告记录策略版本；旧GPIQ/逐级版/20%底仓直达版快照及旧版报告会自动失效并重算。本次不增加迁移。
迁移不删除持仓、现金或历史。已有GPIQ只对分配给S2的份额生成卖出转仓建议，不会自动下单或修改记录。
建议采用20bps单边滑点预算＋IBKR Tiered估算费用，参考最近完整收盘价，真实开盘成交可能偏离。当前配置见
[S2部署快照](../../BACKEND/strategy2/DEPLOYED_RULES.json)。

通常单只ETF的调仓差额达到S2总资产的5%才建议交易；比较实际持仓与当前目标，不比较相邻两日报告。
普通补仓和小幅调仓向下取整为整股，单笔至少80美元且预计手续费不超过成交额0.5%；卖出所得再投入也须通过此过滤，不足时保留现金。费用预算包含每单0.05美元外部费用缓冲，实际以券商预览为准，换汇成本另计。
清仓不受调仓带或成本门槛限制；TQQQ减仓以及震荡／下跌／强下跌时非SGOV减仓不受成本门槛限制，部分卖出仍遵守原5%调仓带。这些卖出支持六位小数，禁止超卖。保留13美元现金预留；目标以扣除预留后的可投资金额计算。
首次切换到直达版时，已有SPMO/QQQM在目标归零后会建议退出，即使金额较小；不会自动成交。

配置 `STRATEGY_AUTORUN=1`、`STRATEGY_PUSH_TIMEZONE=Asia/Shanghai`、`STRATEGY_PUSH_HOUR=10`。
日任务从配置时间起检查真实美股交易日，开盘前失败可重试，开盘后不补发。
每位用户每个策略每个交易日仅存一份报告（数据库唯一约束）；Telegram 临时失败最多重试五次，
不跨日发送旧报告。极端的“Telegram 已接收但进程来不及记录”崩溃仍可能重复发送；Telegram API 不提供幂等发送键。
数据准备失败会发“暂无建议”状态报告，30 分钟后再试；恢复后用同一条数据库记录保存并发送完整报告。

S1 每日检查，月度买入仍由 /auto_notice_date 决定，无需操作也出报告。
/check 依次检查所有已启用策略，单项失败继续检查其他项；/check1 仅检查 S1，/signals 保留为 S1 别名。

S2 /check2 查看趋势、目标持仓与经过费用过滤的操作。/strategy1_pool 查看股票池，+ AAPL MSFT 添加、- AAPL MSFT 移除，支持分条输入与 /cancel；旧 reset 参数仍兼容。首次修改保存当前默认池的个人副本，不影响其他用户。

SIP 行情请求统一将截止时间限制到当前时间的 16 分钟前，包括显式传入的未来截止时间；更早的历史截止时间保持原值。S2 手动检查在收盘后等待这段延迟，再纳入当天日线，避免使用不完整数据。该限制符合 [Alpaca 历史行情权限说明](https://docs.alpaca.markets/us/docs/market-data-faq)，无需改用 IEX。

现金示例（替换余额）：

```
CASH 1 200USD
CASH 2 300USD
```

CSV 对应 `CASH,1,200USD` / `CASH,2,300USD`。编号可预留给未来策略，预留不开放未来策略。

AUD资金也支持，例如`CASH 2 300AUD`或CSV的`CASH,2,300AUD`。汇率自动获取，`/fx`可查看或刷新；无需手填。默认`FX_PROVIDER=truefx`，使用带时间戳的AUD/USD参考买价，30秒缓存，无需额外API密钥。报告显示来源与报价时间，周末显示最近有效报价；无有效报价时暂停AUD建议，不自动换汇或下单。USD/AUD独立预算可混用，持仓份额按USD估值现金占比分配。

本次更新包含迁移`0017_aud_cash`，继续执行下方既有`alembic upgrade head`即可；现有预算默认USD，旧金额不变。
独立现金存在时禁止设置比例；持仓按独立现金占总现金的比例划分计算份额。未启用策略的份额保留。
`CASH 0 500USD` 清除全部独立现金、改为公共现金，随后可 `/strategy_weights 1=60 2=40`。
CSV 的 CASH 0 必须是唯一现金行；重复编号、混用模式或无效数值整次回滚。

常规部署可沿用 systemd 模板和私密环境文件。要求删除凭据文件时，可用 `supervise.py`：
向进程注入环境，启动后立即删除临时文件，环境仅保留在监督进程与 Bot 进程中。
监督进程会在 Bot 异常退出后重启；主机重启或监督进程退出后需重新注入凭据。
进程号在 `data/supervisor.pid`，运行日志在 `data/runtime.log`。两者均不提交。
